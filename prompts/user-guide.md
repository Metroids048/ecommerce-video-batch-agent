# 用户引导

把需要修改的完整视频和要求发给我；有多个视频，说明每条要改什么。需要替换Logo或文字时附新资产，并告诉我哪些人物、商品、文字、声音和剪辑必须保留。我会整理修改范围、执行并检查，给你对应完整视频、前后预览和未解决项。你不需要先逐帧找点或填写技术表格。

例如：“把这条视频里上衣的小REPLAY去掉，下方UNIQUE和手里的Dior都保留，人物动作、字幕和声音不要变，给我完整视频。”

当前是Codex宿主下的开发原型。自然语言理解、全片找点和画质判断由Codex承担；只把需要修改的片段送已授权API，按原时间线回填，局部瑕疵优先用本地视频工具修好，自审后交完整视频。新云端处理按当批授权及总预算执行；失败和返修也计费入限，原批额度不挪用。通用找齐和复杂重建尚未证明，未合格结果会明确标注，用户认可另记。
